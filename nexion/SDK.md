# NEXION CORE SDK v0.1.0 — experimental
Python 3.10+; standard-library runtime. Existing offline research modules retained.
Public facade: nexion.sdk (Swarm, Unit, Task, ResearchAgent, Goal, GoalPolicy, select_model).
Model selection screens paired losses; it does not establish statistical significance, authorize deployment, or modify code. Use untouched confirmation data and human approval.
Run from nexion/: python -m unittest discover -s tests -q
Package in an existing setuptools environment: python -m pip install --no-deps --no-build-isolation .
Flutter/Android, C ABI, real hardware and network integration are not implemented. Preserve app signing and SDK policies. Existing simulation-only authorization restrictions remain intact.
