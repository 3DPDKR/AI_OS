# NEXION 공동연구 개발 환경 / Collaboration environment
2026-11-28 | 공개 운영 안내 / Public-safe operations guide

이 문서 묶음은 운영 체계와 구축 상태만 설명한다. 세부 연구 결과, 알고리즘, 미발표 논문, 개인 정보 및 인증정보는 공개하지 않는다. This is an operational guide, not a release of restricted research.

## 목적
자율형 AI와 분산 지능의 과학적 검증을 최우선으로 하며 ENGINE과 CORE SDK를 분리 개발한다. 생체공학은 후속 비생물 개념·문헌 연구다. 실제 생명체나 의식 구현을 주장하지 않는다. 공동연구는 단독 연구보다 나은 결과를 실증하는 것을 목표로 한다.

## 현황
기존 GitHub 저장소는 공개 상태이며 main을 유지한다. 신규 제한 연구자료 게시 금지. 별도 비공개 연구 저장소, 전용 ChatGPT 프로젝트 및 회원 포털을 실제 검증한 뒤 승인 참여자에게 개별 연결한다. 기존 공개 이력의 회수는 보장할 수 없다. 현재 공개 신청은 의사 표명만 가능하다.
