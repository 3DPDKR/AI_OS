# 운영 환경 및 개통 체크리스트 / Deployment readiness
2026-11-28 기준. 공개 가능한 구성 및 상태만 기록하며 내부 접속정보, 인증키, SQL 상세, 연구 결과는 제외한다.

## 현재 확인된 기반
- GitHub: 3DPDKR/AI_OS 공개 저장소. 모집 이슈 #1 유지. NEXION 이름 변경 미완료.
- 개발 트랙: ENGINE 및 CORE SDK 실험 브랜치 별도 유지. main 변경 금지.
- Supabase: 기존 NEXION 프로젝트 사용. 회원, 제한 연구자료, 공개 명단 및 보호된 관리자 바인딩 테이블 생성 확인. 네 테이블 모두 RLS 활성화. 조회 시 각각 0행.
- 이메일 확인 상태를 등록 조건으로 검사하고 승인 회원에게 연구자료 읽기 권한을 부여하는 정책이 작성됨. 철회 시 공개 명단 제거 정책 작성됨. 실제 사용자 세션 검증 미완료.
- 이전 보안 점검에서 뷰 관련 오류 수정 후 오류 등급 0건, 보호 관리자 테이블의 무정책 RLS 정보 알림 1건. 전체 보안 인증이 아니다.
- 관리자 실제 UUID/MFA 바인딩은 미완료. 이메일 전체 관리자 조회 기능은 보안 문제 있는 뷰 제거 후 재구현 필요.

## 개통 전 필수 작업 (미완료)
1. 기존 공개 연구 저장소와 공개 모집 분리. 새 비공개 저장소 또는 적절한 접근제어 검증. 과거 공개 이력 위험 평가.
2. 비공개 등록·로그인 UI 배포, 이메일 확인 설정·실제 메일 전달 테스트, 개인정보 처리 고지 확정.
3. 본인 인증 후 보호된 관리자 등록, MFA 및 세션 확인, 관리자 이메일 조회와 승인·거절·철회 감사 로그 구축.
4. 공개 명단 UI, 가입·승인 상태 화면, 참여자별 연구자료 UI 및 비공개 접근 테스트.
5. 상호 동의 기반 이메일 연락 또는 중계, 발송 제한, 철회·수신 중단 테스트.
6. 개별 초대 방식 ChatGPT 공동 프로젝트, 자료 공유 동의 및 비공개 제출·통합 자동화 구현.
7. 직접 시작 링크, 모바일/PC 브라우저, 이메일 인증·로그인·관리자 승인 전체 흐름 검증.
8. 선택적 Tor 포털은 독립 환경과 보안 검증 후 별도 승인. 실제 주소 및 가동 미확인.

## 합격 조건
익명·미승인·승인·철회·관리자(AAL1/AAL2) 역할별 접근 테스트; 본인 외 개인정보 차단; 자기 승인 방지; 공개 명단 동의 및 철회 반영; 비공개 연구 결과 외부 접근 차단; 이메일 검증 및 발송 실증; 감사 기록; 비용 확인. 테스트 로그 및 실패 사례는 비공개 보관.
기존 서버 기반만 구축된 상태이며 운영 개통 또는 이메일 발송 성공을 주장하지 않는다. 추가 유료 결제 없이 진행하되 서비스 제한을 확인한다.
