# 공동개발 및 AI 리소스 공유 / Research workflow
## 개발 트랙
ENGINE: 핵심 분산 지능, 안전한 자율 판단, 협력 및 비교 검증.
CORE SDK: 검증된 기능의 독립 라이브러리화, API, 회귀검증 및 응용 호환성.
논문: ENGINE·SDK 알고리즘 중심, 선행연구와 재현 가능한 비교. 생체공학은 별도 후속 트랙.
## 협업 순환 (목표)
승인 참여자에게 비공개 작업공간 초대 → 최신 승인 기준과 연구 과제 확인 → 각자 ChatGPT/Codex 계정으로 연구 → 비공개 결과 제출 → 독립 재현·교차검토 → 관리자 승인 → 실험 브랜치 통합 → 승인된 지식 갱신.
계정·구독 한도·API 키 공유 금지. 개인 대화 자동 수집 금지. 전용 공유 프로젝트는 개별 초대만 허용하고 승인된 자료만 넣는다. 외부 AI 서비스 전송은 별도 명시적 허용 범위에 한정한다. GitHub 자동 동기화 및 공동 프로젝트 자동 연결은 미구축.
## 제출 기록 (비공개 공간 전용)
연구 ID, 분야, 기준 커밋, 가설, 대조군, 코드, 환경·시드, 관측값, 실패 및 한계, AI 사용, 독립 검증 상태, 동의 범위.
## 공동연구 효과 검증
동일 시간·연산 예산·입력 조건의 단독 연구와 공동연구를 비교. 독립 재현률, 검증 개선 수, 중복 시간, 결함 검출, 지연·메모리·통신량, 안전 제약 위반을 기록한다. 우수성은 실측 전 주장하지 않는다.
## 안전과 공개
기존 main 변경 금지. 승인된 실험 변경만 비공개 개발 공간에 통합. 실제 시설·장비 제어, 구매, 생물 실험, 무단 연락 및 비참여자 연구 결과 공유 금지. 외부 논문 제출은 별도 승인. 공개 GitHub 이슈에는 결과 제출 금지.

## 자율성과 승인 경계
승인 범위 내 연구는 자율 수행한다. 원본 통합, 개인 프로젝트 전용, 외부 공개 및 상업적 이용은 [이용 정책](USAGE_POLICY.md)에 따른다. 공익 목적이라도 비공개 연구자료의 외부 제공은 사전 승인 필요.
