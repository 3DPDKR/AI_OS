# NEXION public participation — first live opt-in channel

**Status (2026-11-24):** GitHub public issue is OPEN for voluntary expressions of interest.
https://github.com/3DPDKR/AI_OS/issues/1

## What is operational?
- GitHub-hosted public comments, authenticated by GitHub accounts.
- Volunteer chooses a scope: public discussion, code review, offline simulation.
- Volunteers can withdraw by deleting their own post and/or asking the maintainer to stop processing it.
- This is a *public opt-in expression*, not production membership, real-name verification, or factory authorization.
- No automation sends invitations, scans networks, or collects email addresses.

## What is NOT operational?
- Independent NEXION signup web server, contact database, email OTP, dedicated private applicant dashboard, mass recruitment.
- Automated approval, AI autonomous life, live hardware or manufacturing connections.
- Participant identity or institutional authority verification. A GitHub account only proves control of that GitHub account.

## How to count participation responsibly
Count only distinct GitHub accounts posting an unambiguous affirmative opt-in and scope on issue #1, exclude the project author/maintainer and users who withdraw, and do not count casual comments or reactions. State when a count was checked. Never imply a count is verified people or factory owners. Do not mirror comments or personal data to other services without separate consent.

## Private production portal requirements before launch
1. Separate dedicated server under an explicitly selected organization.
2. Verified login (e.g., magic-link), consent-version audit, purpose and retention policy, export and withdrawal.
3. Scoped least-privilege access with row-level security.
4. Rate limits, abuse reporting, moderation, incident response, privacy/security review.
5. A separate human-verifiable process for organization/factory authority, with no equipment actuation through signup.
6. End-to-end test of registration, withdrawal and unauthorized access rejection.

The research branch must remain separate from the main branch.
