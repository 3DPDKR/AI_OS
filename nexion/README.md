# NEXION — 분산 지능 실험 v0.1.0
2026-11-10. 시작점은 비(非)인간형 지능적 존재 연구이며, 현재는 **오프라인 소프트웨어 시뮬레이터**입니다.

이 브랜치는 기존 AI_OS 앱의 main 기능을 변경하지 않습니다.

## 구현
- 3개 분산 개체의 임무 배분과 장애 시 재할당
- 관측 데이터에 근거한 자율 *연구 목표* 선택 및 감사 기록
- 미승인 생산시설 등록 차단, 실제 설비 연결 및 가동 차단
- 무인 자동 발주, 네트워크 스캔, 생산 명령을 수행하지 않음

## 실행 (Python 3.9+, 추가 패키지 불필요)
```sh
cd nexion
python -m nexion.core
python -m nexion.agent
python -m unittest discover -s tests -v
```

## 실제 연결의 필요조건
생산시설 담당자의 시설별 개별 동의, 신원/권한 검증, 읽기 전용 테스트 환경, 독립 안전성 평가, 현장 E-stop 및 승인 절차. 이 버전에는 실제 장비 가동 기능이 없습니다.

## 설계 원칙
자율 목표 선택은 자기 목적/의식의 증거가 아닙니다. 현재 목표 선택은 감사 가능한 결정론적 규칙입니다. 외부 액추에이터 구동, 구매, 시설 제어는 허용되지 않습니다.
