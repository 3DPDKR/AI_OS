# NEXION v0.3.1 — 2026-11-21

**범위:** 오프라인 Python 패키지 import 경로 복구 및 실행 가능성 회귀 검증. 기존 기능·데이터 구조·전송 및 복구 로직의 변경 없음.

## 발견된 회귀

v0.3.0에서 `nexion/evidence_triage.py`를 저장소 프로젝트 루트에 생성했지만, 실제 `nexion.evidence_triage` 패키지 import에는 `nexion/nexion/evidence_triage.py`가 필요했다. 실험 브랜치의 이전 상태를 로컬 재구성하여 테스트했을 때, 166개가 실행되고 `test_evidence_triage` 모듈 로딩에서 ImportError 1건이 발생했다. 당시 GitHub 브랜치가 그대로 183개를 통과한 것은 아니었다.

## 수정 및 검증

- 코드를 변경하지 않고 올바른 Python 패키지 위치로 옮기고, 잘못된 경로의 복사본을 삭제.
- 재발 방지용 import 경로/문서화된 실행 명령을 확인하는 신규 테스트 4개 추가.
- 올바르게 배치한 v0.3.0 대상 테스트 18개 통과.
- 전체 187개 테스트 5회 반복: 935/935 통과 (Python 3.13.5 로컬 재구성 환경).
- `python -m compileall -q nexion tests` 완료.
- 새로 반영한 3개 파일의 Git blob SHA를 로컬과 GitHub에서 대조하여 일치 확인.
- 기본 `main` 브랜치에는 쓰기 작업 없음; GitHub Python CI 결과는 확인되지 않음.

## 다음 단계
