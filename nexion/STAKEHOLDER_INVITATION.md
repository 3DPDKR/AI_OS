# NEXION 관련 연구자·시설 운영자 참여 제안 (미발송)
NEXION은 분산형 자율 로봇을 위한 초기 연구입니다. 현재 성과는 오프라인 임무 배분, 장애 우회, 자율 연구 목표 선택 시뮬레이터입니다.

협력 대상: 로봇 연구팀, 산업자동화 연구자, 소형 제조시설의 실제 운영 담당자, 제품 안전 전문가.
초기 참여: 설계 검토, 제어 없는 시뮬레이션 결과 검증, 읽기 전용 데이터의 동의 기반 공유.
시설 연결은 시설별 권한 증명, 서면 범위, 운영자 직접 승인, 안전 인터록 확인 후에만 가능합니다.
실제 설비 제어/제작/구매 권한을 요청하거나 가정하지 않습니다. 이 초안은 어떤 기관에도 발송되지 않았습니다.
