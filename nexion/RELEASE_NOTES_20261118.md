# NEXION v0.2.8 · 2026-11-18

## 검증 범위

- 복구 승인 마지막 확인 예외 시 상태가 `APPROVED`로 남던 메모리 상태 전이 문제 수정.
- 복구 작업지시서와 데이터 지문을 재검증하는 **읽기 전용** `recovery_preflight.py` 추가. 반환 결과는 실행 불가.
- 승인 스냅샷에 SQLite `audit` 테이블 포함. 감사 기록 단독 변경 감지.
- 신규 오프라인 장애 주입 테스트 **10개** 추가. 기존 146개 유지, 총 **156개 테스트** 통과.
- 기본 `main` 브랜치와 기존 생산 기능 변경 없음.

## 제한

실행 가능한 복구, 타 시스템 접속, 외부 연락, 실물 설비 제어, 자동 구매는 구현하지 않았습니다. 두 번 읽는 것으로 **DB 간 TOCTOU 경쟁 조건을 완전히 막지 못하며**, 인증된 신원 검증, 실서비스 권한 및 내구성 있는 원자적 복구 기능을 제공하지 않습니다. 추가 설계는 `RECOVERY_PREFLIGHT.md` 참조.
