# AI OS

Multi-Agent AI Operating System for Android.

## Goal
AI OS automatically selects enabled AI providers and tools, validates evidence, and produces the best final result instead of running endless AI discussions.

## Main UI
- 채팅
- AI 대화방
- 기록
- 설정

## Development
- Smartphone-first development
- Flutter Android app
- GitHub Actions cloud APK build
- Free AI providers first
- Paid API disabled by default
- Local-Light storage + optional cloud archive
